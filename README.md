# 貸款結清試算工具

免費、繁體中文、優先為 iPhone 設計的汽車貸款結清試算網站。使用原生 HTML、CSS、JavaScript；不需要安裝套件、後端、資料庫、登入或 API 金鑰。輸入資料不會上傳，所有運算在瀏覽器執行，也不使用外部字型或追蹤服務。

## 檔案

- `index.html`：輸入表單、結果、可展開明細與重要聲明。
- `style.css`：白色、深藍、淺藍色響應式版面。
- `script.js`：精確攤還計算、驗證、顯示、複製及手動複製備援。
- `tests/calculator.test.js`：不需第三方套件的 Node.js 自動測試。
- `tests/browser.cjs`：選用的 Playwright 瀏覽器驗證。
- `README.md`：操作、公式、驗算與部署說明。

## 直接使用

用瀏覽器開啟 `index.html` 即可試算；使用 GitHub Pages 的 HTTPS 網址時可啟用瀏覽器剪貼簿。若權限被拒絕或在本機開啟，網站會提供文字框供長按全選、手動複製。

本金、總期數、年利率、月付款與已繳期數均可修改。年利率與月付款擇一填寫，輸入後即自動帶入另一欄；兩欄都有值時，以最後手動修改的欄位為準。修改本金或期數時，也會依目前的輸入來源重新換算。年利率模式下，月付款顯示為進位整數，但計算仍保留精度；月付款模式以原始輸入月付款反推年利率（畫面顯示至小數第 8 位，計算使用完整精度）。月付款低於本金除以總期數，或反推年利率超過 100% 時會提示檢查資料。按「開始試算」後顯示結果；修改輸入會隱藏舊結果，避免誤用。「重新計算」保留原輸入，回到本金欄供修改，再按「開始試算」。點選「本息平均攤還明細」可展開表格；手機上可左右滑動表格。

本機 HTTP 驗證（已安裝 Python 3 時）：

```sh
cd /workspace/loan-settlement-calculator
python3 -m http.server 8000 --bind 127.0.0.1
```

這只是本機測試服務，不能視為已公開部署。按 Ctrl+C 停止。

## 計算方式

假設固定利率、每月一期，已繳期數均正常繳付完整月付款；不計算按日利息、遲繳、額外手續費、保險或不規則提前還款。

本金為 P、總期數為 n、月利率 r = 年利率百分比 / 1200：

- r > 0：月付款 M = P × r / (1 − (1+r)^(-n))。
- r = 0：月付款 M = P / n。
- 每期利息 = 上期剩餘本金 × r。
- 每期攤還本金 = M − 每期利息；最後一期清償餘額，排除浮點運算尾差。
- 以未進位數值逐期計算剩餘本金 B(k)。

設已繳期數為 p、補足終點 t = max(p, min(20, n))：

- 補足期數 = t − p。
- 未全部繳清：結清總額 = M × (t − p) + B(t) × 1.03。
- p = n：結清總額 = 0。
- n < 20：只補足至合約最後一期，不收取不存在的期數；末期剩餘本金為 0，所以沒有剩餘本金加計 3%。這是本工具的短期合約假設，實際仍應核對合約。

**剩餘本金**顯示的是結清公式使用的本金：未滿綁約期時為補足至第 20 期後的本金；滿 20 期後為目前的本金。畫面會標示對應期數。

所有金額使用未進位數值運算，僅對外顯示時無條件進位至整數元，並加入千分位逗號。各顯示值相加可能與總額有數元差異。程式只在整數邊界消除 JavaScript 浮點誤差；不會將每期顯示後的月付款重新代入計算。

本金支援 1～1,000,000,000,000 元整數；總期數 1～1,200 期整數；年利率 0～100%（可含小數）；已繳期數為 0～總期數整數。空白、負數、超繳與非數字均會提示錯誤。

## 自動測試與驗算

安裝 Node.js（建議 24 LTS），在專案目錄執行，不需 npm install：

```sh
node --test tests/calculator.test.js
```

18 項測試涵蓋指定期數、獨立現金流折現驗算、72 期攤還表、本金守恆、零利率、進位時機、短期合約、極低利率、全額繳清、錯誤輸入，以及月付款反推年利率的雙向換算。

可重複驗算：本金 600,000 元、總期數 72 期、年利率 5%，月付款顯示 **9,663 元**。

| 已繳期數 | 需補足期數 | 公式採用的剩餘本金（元） | 預估結清總金額（元） |
| --- | --- | --- | --- |
| 0 | 20 | 450,926 | 657,713 |
| 8 | 12 | 450,926 | 580,410 |
| 12 | 8 | 450,926 | 541,758 |
| 19 | 1 | 450,926 | 474,117 |
| 20 | 0 | 450,926 | 464,454 |
| 21 | 0 | 443,142 | 456,436 |
| 72 | 0 | 0 | 0 |

進位驗算：本金 100 元、總期數 3 期、利率 0%、已繳 0 期，月付款顯示 34 元，結清金額應為 100 元，不能以 34 × 3 得到 102 元。

選用瀏覽器測試：先啟動上述本機 HTTP 服務，安裝 Playwright 與 Chromium 後執行：

```sh
node tests/browser.cjs
```

此測試需要 Node.js 能載入 `playwright`，並預設使用 `/usr/bin/chromium`。其他位置可設定 `CHROMIUM_PATH`；其他本機測試網址可設定 `TEST_URL`。這些工具只用於開發測試，公開網站無需安裝。測試涵蓋 320、390、1440 像素寬度的表單操作、所有指定期數、錯誤訊息、明細、重新計算、複製成功／拒絕權限備援與頁面水平溢出。

## 提交到 GitHub（使用電腦或此開發環境）

本次建立檔案不等於已提交或推送。請先檢查變更，再執行：

```sh
cd /workspace/loan-settlement-calculator
git status
git add index.html style.css script.js README.md tests/calculator.test.js tests/browser.cjs
git commit -m "建立繁體中文貸款結清試算網站與測試"
git push origin main
```

需具有儲存庫寫入權限。若本機路徑不同，請先進入自己的專案目錄；若 Git 尚未設定提交者名稱與電子郵件，請依 Git 提示設定自己的資料，不要填入他人身分。

## 只有 iPhone：上傳檔案

1. 先將交付的網站檔案下載至 iPhone「檔案」App；若為 ZIP，點一下解壓縮。
2. Safari 開啟 `https://github.com/eric2175333/loan-settlement-calculator` 並登入有寫入權限的帳號。
3. 在 Safari 網址列旁「頁面選單」（部分版本顯示 aA）點「要求桌面版網站」，必要時橫向操作。
4. 儲存庫點 **Code**，確認分支 **main**；點 **Add file → Upload files → choose your files**。
5. 從「檔案」App 選取 `index.html`、`style.css`、`script.js`、`README.md`，放在儲存庫根目錄，不要再包一層資料夾。README 如提示覆寫，確認是本次新版說明。
6. 在 **Commit changes** 區填寫「建立貸款結清試算網站」，選擇直接提交至 **main**，按綠色 **Commit changes**。上傳會公開到儲存庫，請勿選取私人資料。
7. 測試檔不影響網站上線；要保留測試，另進入或建立 `tests` 資料夾並上傳兩份測試檔。若網頁無法直接建立資料夾，可用 **Add file → Create new file**，檔名填 `tests/calculator.test.js` 或 `tests/browser.cjs`，貼上交付內容後按 **Commit changes**。

GitHub 介面文字可能隨版本不同；若找不到按鈕，優先切換桌面版網站。只有儲存庫擁有者／管理員可設定 Pages。

## 使用 GitHub Pages 公開網站

不需付費 API。GitHub Free 通常需使用公開儲存庫；私人儲存庫請依帳戶方案確認 Pages 權限。不要為此公開含有私人資料的其他專案。

1. 確認上述檔案已提交至遠端 **main**。
2. Safari 使用桌面版 GitHub，進入儲存庫 **Settings**；若導覽被收合，先點 **…** 找到 Settings。
3. 在設定側欄點 **Pages**（通常在 Code and automation 下）。
4. **Build and deployment → Source** 選 **Deploy from a branch**。
5. **Branch** 選 **main**，資料夾選 **/ (root)**，按 **Save**。
6. 等待數分鐘。到 **Actions** 查看 **pages build and deployment** 是否成功（綠色勾號）；若失敗，點入查看錯誤，勿將失敗視為已發布。
7. 回 **Settings → Pages**，成功後點 **Visit site**。預期網址是 `https://eric2175333.github.io/loan-settlement-calculator/`，但須以 GitHub 顯示的實際網址為準，這裡不表示已部署。
8. 在 iPhone 開啟網站，輸入上述範例，確認已繳 12 期結果為 541,758 元；再測試展開表格與複製。

後續更新只需提交到 main，Pages 會重新部署。若出現 404，先確認 Pages 部署成功、根目錄有小寫的 `index.html`，再等候並重新整理。

## 重要聲明

本工具僅供提前結清金額初步試算，不代表任何金融機構正式結清報價。實際金額仍應依貸款契約、繳款紀錄及金融機構結清明細為準。
